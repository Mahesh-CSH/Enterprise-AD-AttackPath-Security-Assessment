# AP-01 — USER1 GenericAll Over CLIENT

## Starting Principal
USER1@AD.LAB

## Target
CLIENT.AD.LAB / CLIENT$

## Confirmed Relationship
GenericAll

## ACL Validation
Impacket dacledit confirmed:

- Trustee: USER1
- Access Mask: FullControl (0xF01FF)
- ACE Type: ACCESS_ALLOWED_ACE
- ACE Flags: CONTAINER_INHERIT_ACE

## Execution Validation
USER1 successfully executed a command on CLIENT through SMB/atexec.
The resulting security context was NT AUTHORITY\SYSTEM.

## Attack Path
USER1@AD.LAB
    |
    | GenericAll / FullControl
    v
CLIENT.AD.LAB
    |
    | Controlled execution validation
    v
NT AUTHORITY\SYSTEM

## Security Impact
Excessive control over a computer account can provide a low-privileged
domain user with unintended control over a domain-joined endpoint and
potential paths to further lateral movement or privilege escalation.

## MITRE ATT&CK
To be finalized after the complete attack path is validated.

## Remediation
- Remove unnecessary GenericAll permissions from USER1.
- Apply least-privilege delegation to computer objects.
- Review inherited and delegated ACLs.
- Retest the relationship after remediation.
