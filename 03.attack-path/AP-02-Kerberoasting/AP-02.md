# AP-02 — Kerberoasting: Service Account Credential Exposure

## Finding

A domain service account was identified with a Kerberos Service Principal Name (SPN),
making it susceptible to Kerberoasting.

## Starting Principal

`user2`

## Target Account

`mysql`

## Target SPN

`DC01/mysql.AD.lab:60500`

## Attack Path

```text
USER2
  |
  | Authenticated AD Enumeration
  v
MYSQL service account
  |
  | Kerberos SPN discovered
  v
TGS-REP requested
  |
  | Offline password analysis
  v
Service account credential recovered
